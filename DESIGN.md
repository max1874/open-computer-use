# Design record

Verdicts on how this project presents itself, so a rejected idea does not come back.

## README hero

- 2026-11-05, Calculator demo GIF (`docs/demo.en.gif`) and Calculator sample output: rejected. Max: "放一个计算器也太 low 了". Pressing digits shows that buttons can be pressed, not that the agent works while you keep using your Mac.
- 2026-11-05, a screen recording with TextEdit in front: rejected ("TextEdit 也不行吧").
- 2026-11-05, any capture of the maintainer's real desktop: rejected after a staged still exposed his Apple account name ("我大名都暴露了"). Hero material never comes from the maintainer's screen or from changing his system settings; it is drawn from data the tool printed.
- 2026-11-08, three directions shown side by side (A two screens, B terminal session, C X-ray). Max picked **C** explicitly ("c 吧"): the window as the agent reads it, an indexed control table drawn over System Settings, with an editor in front. `docs/demo.gif` is that direction, replayed from one real `observe` / `act` on System Settings › Appearance; indices, labels, states and results are the tool's output and the geometry is drawn.
